# Residents

One markdown file per resident, 20 in all. Rendered at `/residents/<slug>/`
and listed on `/residents/` grouped by affiliation.

Frontmatter that matters:

```yaml
title: "Cody Marx Bailey"
photo: "/media/2012/02/CodyProfile__001.jpg"   # omit to use the placeholder
affiliation:
  - "Alumnus"          # grouping on the residents page + photo ribbon
fields:
  Be Page Subtitle: "Catalyst"                 # role line under the name
```

The body is the bio. All residents are Alumnus now that the space is closed.
